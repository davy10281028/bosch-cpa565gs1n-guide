⚡30 秒速查：最常用的操作

本機操作邏輯：左旋鈕選功能 → 右旋鈕調數值（溫度／時間／重量）→ 按 start / stop。左旋鈕轉回最上面「0」＝關機。

⚠ 最重要的三條
  • 微波模式絕不能空機啟動（裡面一定要有食物），也不能放金屬容器、金蔥/金邊餐具。
  • 用蒸氣功能前，水箱一定要加水；連續缺水啟動會出現 E5005。
  • 開門時小心熱蒸氣（溫度高時蒸氣看不見）；拿取配件一定要戴隔熱手套。

1第一次使用前要做的事

  1. 撕掉保護膜、清空爐內：取出所有包材與配件，爐內不要留任何東西。
  2. 設定時鐘：第一次通電時時間會閃爍 → 右旋鈕調時間 → 按 ⏱ 確認。
  3. 設定水質硬度（影響除鈣提醒頻率）：關機狀態下長按 ⏱ 數秒進入基本設定 → 重複按 ⏱ 切到「水質硬度」→ 右旋鈕選 0～4 → 再長按數秒儲存（見設定表）。
  4. 空燒去味：用濕軟布擦拭爐腔 → 關門、廚房開窗通風 → 左旋鈕轉到 熱風 → 右旋鈕調 180°C → start → 1 小時後轉回 0，等冷卻。
  5. 清洗配件：烤架、玻璃烤盤、蒸盤用中性洗碗精＋軟布洗淨。
  6. 第一次用蒸氣前：建議先跑一次 沖洗程序，把管路沖乾淨。
💡 實用建議（非原廠手冊內容）
  • 台灣自來水多為中硬水，若不確定可先設 3（硬）；家裡有軟水機或用 RO/過濾水可設 1～2。
  • 空燒時會有新機味和少量白煙，屬正常。
  • 手冊封面的貼紙（自動程式編號表）可以貼在機身旁，選程式時比較方便。

4微波操作

  1. 食物放在微波可用容器（玻璃、陶瓷、耐熱塑膠），直接放爐底。
  2. 左旋鈕轉到 〰 微波，螢幕預設顯示最高瓦數。
  3. 重複按 〰 選瓦數，螢幕出現建議時間。
  4. 右旋鈕調時間 → start。過程中也可以轉右旋鈕改時間。
  5. 時間到會嗶聲、自動停止；轉回 0 關機。

⚠ 注意
  • 加熱液體要放一支湯匙防止突沸；湯匙要離爐壁和門至少 2 cm，否則會冒火花。
  • 雞蛋（帶殼或整顆水煮蛋）不要用微波加熱，會爆。
  • 加熱嬰兒奶瓶要拿掉奶嘴和蓋子，360W 約 0.5～1.5 分，搖勻後一定要試溫。

5蒸氣操作

強度適合
1（低）解凍蔬菜、肉、魚、水果
2（中）甜點（布丁、蒸蛋）、魚、香腸、包子饅頭
3（高）蔬菜、魚、配菜、川燙、蒸水果取汁
  1. 拿掉烤架，玻璃烤盤放第 3 層，蒸盤放進玻璃烤盤，食物放蒸盤上。
  2. 左旋鈕轉到 ♨ 蒸氣，預設強度 3、20 分，水箱箭頭會閃。
  3. 按水箱蓋中間打開 → 取出水箱 → 加冷水到 MAX → 推到底 → 蓋上。
  4. 按 ♨ 選強度、右旋鈕調時間 → start。
  5. 時間到會嗶聲。小心開門，讓蒸氣先散一下。
  6. 蒸完：擦乾爐腔底部的集水槽和爐內水氣，建議跑一次沖洗，再倒空、擦乾水箱。
一箱水可以用多久
  • 純蒸氣（強度 3）：約 30～40 分；強度低更久。中途沒水會暫停、水箱箭頭閃，加水後按 start 繼續。
  • 蒸氣＋微波：約 50 分，沒水會暫停。
  • 燒烤＋蒸氣：約 3 小時；沒水會繼續烤但不加蒸氣，不會提示。
⚠ 注意
  • 水箱只能加水（或原廠除鈣液），不可加酒精等易燃液體。
  • 運作時水箱會變熱，等冷卻再拿。水箱和集水盒不可放洗碗機。
  • 運轉時有「嗡嗡」聲是幫浦正常聲音。很久沒用蒸氣，先跑一次沖洗。

6烤箱（熱風）與燒烤

熱風 / 熱風燒烤

  1. 左旋鈕轉到 熱風 或 熱風燒烤，螢幕顯示預設溫度。
  2. 右旋鈕調溫度；需要時按 ⏱ 兩下設烹調時間。
  3. （建議）短按 ⇡ 開快速預熱（溫度 100°C 以上才有，最多 15 分自動結束）。
  4. start。下方紅條 5 格全紅或快速預熱嗶聲後，再放食物。
💡 發酵麵團麵團放碗裡蓋保鮮膜，放爐底 → 熱風選 40°C（40°C 無快速預熱，也不能在運轉中改成 40°C）。

全面燒烤（上火）

  1. 左旋鈕轉到 燒烤 → 右旋鈕選段數 1～3。
  2. 設時間 → start。燒烤時紅條會整條亮。
  3. 食物直接放烤架（第 3 層），玻璃烤盤放第 1 層接油；關門燒烤。

燒烤時加熱管會一亮一滅、可能有少量煙，都是正常的。肉烤好再撒鹽比較多汁；用夾子翻面，不要用叉子戳。

7組合模式（微波＋烤、蒸氣＋烤）

這台最強的地方：烤的時候加微波＝更快熟、烤的時候加蒸氣＝外酥內嫩不乾。

加微波（MicroCombi）

  1. 左旋鈕轉到熱風 / 燒烤 / 熱風燒烤 / 蒸氣，右旋鈕調溫度或段數。
  2. 按 〰 選微波瓦數（不能用 1000W）→ 右旋鈕設時間 → start。

加蒸氣

  1. 左旋鈕轉到熱風 / 燒烤 / 熱風燒烤 / 微波，調好溫度或瓦數。
  2. 按 ♨ 選強度（再按到最低之後會關掉蒸氣），水箱圖示出現 → 加水。
  3. start。過程中盡量不要開門，會影響效果。
限制微波 1000W、熱風 40°C 不能組合。組合模式請用耐熱又可微波的容器；組合模式下可以用一般金屬烤模，但若烤模與烤架之間冒火花，換位置或改成不加微波。

沖洗程序（Rinse）

  1. 左旋鈕轉到 沖洗（時間固定，不能改）。
  2. 打開水箱蓋 → 取出集水盒倒空後推回。
  3. 水箱倒掉殘水、沖乾淨，加新鮮清水推回 → 蓋上水箱蓋。
  4. start，機器把水打過管路排到集水盒，結束會嗶聲。
  5. 倒空、擦乾集水盒和水箱，左旋鈕轉回 0。

集水盒裡有白色小顆粒＝被沖下來的水垢，正常。

11除鈣（Descale）

什麼時候要做
  • 螢幕出現除鈣符號＝只剩 5 次以內的蒸氣操作。
  • 不除鈣的話，所有蒸氣功能會被鎖住（微波、烤箱仍可用）。
  • 頻率取決於水質硬度設定與蒸氣使用次數。

準備

除鈣劑（Bosch 原廠）調配
液體除鈣劑（料號 00311680）50 ml 除鈣劑 ＋ 250 ml 水（1:5）
除鈣錠（料號 00311864，18 g）1 錠放入 250 ml 水，溶解 5 分鐘

步驟（總共約 32 分）

  1. 左旋鈕轉到 除鈣（時間固定約 31 分）。
  2. 打開水箱蓋 → 集水盒倒空推回。
  3. 取出水箱，倒入除鈣溶液，推到底 → 蓋上水箱蓋 → start。
  4. 約 31 分後嗶聲、機器暫停。
  5. 打開水箱蓋 → 倒空集水盒推回 → 水箱徹底沖洗、加清水推回 → 蓋上。
  6. 按 start，自動沖洗 2 次（約 1 分），結束嗶聲。
  7. 倒空、清洗、擦乾集水盒和水箱，左旋鈕轉回 0 完成。
⚠ 一定要跑完除鈣中途中斷，蒸氣功能會被鎖住，需再跑一次沖洗才能恢復。只用原廠建議的除鈣劑（醋、檸檬酸等可能損壞機器，作用時間也是依原廠產品設計的）。除鈣液沾到面板要馬上用水擦掉。

原廠除鈣劑可在 Bosch 台灣官方購物商城或客服購買，購買時報機器型號 CPA565GS1N。
